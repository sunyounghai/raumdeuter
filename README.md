# Raumdeuter — Vision AI 기반 공간 침투 분석 시스템

Vision AI(객체 검출, 트래킹, 호모그래피)를 활용해 일반 방송 축구 영상만으로 선수의 오프더볼 공간 침투를 정량화하는 프로젝트입니다.

## 진행 상태
- [x] 프로젝트 설계
- [ ] 데이터 구축 (진행 중: 1차 파일럿 프레임 추출/필터링 단계)
- [ ] 검출 모델 파인튜닝
- [ ] 트래킹
- [ ] 호모그래피
- [ ] 지표 계산

## 현재 작업: 데이터 구축
먼저 균등 프레임 추출(10프레임 간격)로 GT 생성 → 검출 결과 비교까지 파이프라인 전체가 도는지 빠르게 검증하는 1차 파일럿을 진행 중입니다. 이후 카테고리 기반 의도적 선별로 데이터 다양성을 보강할 계획입니다.

## 알려진 한계
- 검출 모델은 단일 경기 영상으로 학습됨. 다른 방송사/경기장/카메라
  셋업에 대한 일반화 성능은 검증되지 않음 (향후 과제).

## 기술 스택
- 객체 검출/트래킹: YOLOv8/v11, ByteTrack, PyTorch
- 카메라 보정: OpenCV, Keypoint Detection 기반 호모그래피 자동화
- 공간 분석: SciPy(Voronoi), Pitch Control, NumPy/Pandas
- 시각화: mplsoccer, Matplotlib
