# 데이터 추출 로그

## 원본 영상
- 경로: `data/raw_video/1_720p.mkv`
- fps: 25
- 내용: 전반전 45분

---

## 1차 파일럿 (파이프라인 검증용)

**목적**: GT 생성 → 검출 알고리즘 비교 → YOLO 학습까지 전체 파이프라인이 끝에서 끝까지 도는지 빠르게 확인. 데이터 다양성보다 속도 우선.

**추출 방식**: 10프레임 간격 균등 추출(25fps 기준 초당 2.5장) 후, 광각 메인캠 + 피치 라인 keypoint 확인 가능한 프레임만 수동 필터링.

**명령어 템플릿**:
```bash
ffmpeg -ss [시작] -i data/raw_video/1_720p.mkv -t [길이] \
  -vf "select='not(mod(n\,10))'" -vsync vfr [출력폴더]/frame_%04d.jpg
```

**필터링 기준**: 광각 메인캠(경기장 넓게 잡힘) + 대부분 피치 라인 keypoint 4개 이상 식별 가능한 프레임만 유지. 클로즈업, 관중, 리플레이성 반복 프레임은 제외.

**추출 구간 이력**:

| 구간명 | 시작 | 길이 | 원본 추출량 | 필터 후(예상) | 주요 내용 | 폴더 |
|---|---|---|---|---|---|---|
| segment_1 | 04:47 | 120초 | 300장 | 약 150장 | 오픈플레이, 코너킥 | `data/frames_pilot_1/` |
| segment_2 | 07:07 | 81초 | 200장 | 약 170장 | 오픈플레이 위주 | `data/frames_pilot_2/` |
