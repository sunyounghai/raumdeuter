# 라벨링 가이드라인

검출 GT(`player` 단일 클래스) 라벨링 시 일관되게 적용하는 판단 기준.
라벨러(본인)가 매번 판단이 흔들리는 걸 방지하기 위해, 애매한 경우가
나올 때마다 이 문서에 기준을 추가한다.

---

## 1. 프레임 채택 여부 (박스를 그리기 전에 먼저 판단)

라벨링 대상 프레임인지 아닌지를 결정하는 상위 기준. 아래 두 조건을
모두 만족해야 라벨링 대상이다.

### 1-1. 광각 메인캠 샷인가
- 경기장이 넓게 잡히는, 방송 중계에서 대부분의 시간에 나오는 기본 카메라
- 클로즈업, 리플레이, 관중 컷, 감독 얼굴 클로즈업 등은 **제외**

### 1-2. 피치 라인 keypoint가 충분히 보이는가
- 호모그래피(좌표 변환) 계산에는 최소 4개의, 한 직선 위에 몰리지 않은
  keypoint가 필요함
- 눈으로 확인하는 기준: 페널티박스 모서리, 센터서클과 하프라인 교차점,
  코너 지점처럼 서로 다른 위치의 특징점을 2~3개 이상 짚을 수 있으면 통과
- 직선 하나만 화면을 가로지르는 경우(예: 터치라인만 비스듬히 지나감)는
  불충분 — 제외
- 꼭짓점이 1~2개만 보이는 경우도 불충분 — 제외

### 예외 — negative 카테고리(아래 4번)는 이 기준을 적용하지 않음
감독/벤치, 완전 배경처럼 애초에 좌표 산출 대상이 아닌 negative
프레임은 (1-2) 라인 확인 기준에서 면제된다. 다만 (1-1) 광각 메인캠
기준은 negative 프레임에도 그대로 적용된다 — 즉 클로즈업으로 잡힌
감독 얼굴 같은 프레임은 negative 용도로도 쓰지 않는다.

---

## 2. 화질 관련 판단

### 2-1. 모션블러
- 형태(머리-몸통-다리 라인)와 유니폼 색이 흐릿해도 구분 가능하면 포함
- 완전히 뭉개져서 사람인지 배경인지도 확신이 안 서는 수준이면 제외

### 2-2. 원거리로 작게 보이는 선수
- 픽셀 수가 적어도 사람 형태로 식별 가능하면 포함 (원거리 풀샷 카테고리)

---

## 3. 인물별 라벨링 판단 (박스를 그릴지 말지)

### 3-1. 기본 원칙
**"팀 유니폼 착용 + 현재 플레이에 관여 중인가"**로 판단한다.
지리적 위치(경기장 안/밖)로 판단하지 않는다.

| 케이스 | 판단 |
|---|---|
| 필드 플레이어 (일반 플레이 중) | 포함 |
| 골키퍼 | 포함 (별도 클래스로 안 나눔, `player`로 통합) |
| 코너킥/스로인 키커 (라인 밖에 서 있어도) | 포함 — 지금 플레이의 당사자 |
| 파울 판정 대기 중 서 있는 선수 | 포함 — 경기 중단 상태여도 참여 중 |
| 심판 | **제외** (박스 안 그림, negative) |
| 감독/코치 | **제외** |
| 벤치에 앉은 교체 대기 선수 | **제외** |
| 터치라인 밖에서 몸 풀거나 교체 대기 중인 선수 | **제외** — 필드에 아직 안 들어감 |
| 볼보이, 관중, 의무팀, 대기심/스태프 | **제외** |

### 3-2. Occlusion(가려짐) 처리
- **몸통 일부라도 식별 가능하면 라벨링한다.** 제외 기준을 쓰면 밀집
  상황(코너킥, 골 경합 등) 데이터의 상당수를 잃게 되므로 지양.
- 얼굴이 안 보여도 무방 — 검출 모델은 얼굴이 아니라 사람 형태 전체를
  본다.

### 3-3. 화면 경계에 잘린 경우
- 박스는 **보이는 부분까지만** 그린다. 실제 몸이 화면 밖으로 이어질
  것을 추측해서 확장하지 않는다.

### 3-4. 그래픽(스코어보드 등)에 가려진 경우
- 마찬가지로 **보이는 부분까지만** 그린다. 그래픽 뒤에 가려진 부분을
  추측해서 박스를 확장하지 않는다.
- 박스 안에 그래픽 픽셀이 일부 섞이는 것 자체는 정상(사각형 박스의
  본질적 한계이며 표준 관행). 다만 그래픽이 인물의 대부분(약 60~70%
  이상)을 가려 실제 보이는 신체 비율이 너무 낮으면 라벨링에서 제외.

### 3-5. 몸의 중간이 다른 것에 가려 끊겨 보이는 경우
- 머리와 다리처럼 양쪽 끝이 다 보이고 중간(몸통)만 가려진 경우 →
  하나의 박스로, 가려진 중간 부분까지 포함해서 그린다 (한 사람 =
  한 박스 원칙). 이 경우는 3-3/3-4의 "보이는 부분까지만" 원칙과
  달리, 중간에 사람이 있다는 게 명백하므로 이어서 그림.
- 한쪽 끝만 보이고 나머지 방향으로는 어디까지 이어지는지 알 수 없는
  경우(화면 경계, 그래픽에 부분적으로 가려짐)는 3-3/3-4 원칙 적용.

### 3-6. 애매해서 판단이 안 서는 경우
- 몸통/유니폼 색 등 최소한의 식별 정보가 하나라도 있으면 포함
- 머리카락이나 피부색 일부만 보이는 등 형태·색상 정보가 전혀 없으면
  보수적으로 제외

## 4. Negative 카테고리 (박스 없이 프레임에만 포함)

목적: 검출 모델에게 "이 형태는 선수가 아니다"를 가르치는 negative 신호.

| 유형 | 확보 방법 |
|---|---|
| 심판 | 오픈 플레이 등 정상 카테고리 프레임 안에서 자연스럽게 등장. 흔함 |
| 감독/벤치 | 터치라인 근처 액션(스로인 등) 발생 시 광각 프레임에 자연스럽게 걸림. 비교적 흔함 |
| 완전 배경(사람 없음) | 경기 시작 전, 골킥/세트피스 준비 중 빈 공간을 비출 때 드물게 등장. 의도적으로 찾아야 함 |

이 카테고리들은 (1-2) 라인 확인 기준은 면제되지만 (1-1) 광각 메인캠
기준은 그대로 적용됨.

---

## 5. 클래스 설계 원칙 (참고)

- 검출 단계에서는 `player` 단일 클래스만 사용. 팀 구분, 골키퍼 구분은
  하지 않음.
- 이유: 검출(사람이 어디 있는가)과 분류(누구인가)는 다른 문제이며,
  골키퍼처럼 표본이 극히 적은 클래스를 지금 단계에서 나누면 클래스 간
  샘플 불균형으로 학습이 불안정해짐. 팀/역할 구분은 검출 이후 별도
  분류 단계(색상 클러스터링 등)에서 처리 예정.

## 개정 이력

이 문서는 라벨링 진행 중 애매한 케이스가 새로 발견될 때마다 기준을
추가하는 방식으로 갱신한다. 기준이 바뀌면 이미 라벨링된 데이터와의
일관성 문제가 생길 수 있으므로, 변경 시점과 이유를 아래에 기록한다.
